# Changelog

## 0.1.0-dev.6 — 2026-10-08

- Add optional literal blocked phrases and repeated-message hiding with configurable scopes and exact channel lists.
- Add character-name and custom-phrase mentions, whole-word matching, configurable text color and optional native sound with a shared cooldown.
- Keep filters active independently of history collection and preserve native events, links, whisper behavior and later addon ownership.

## 0.1.0-dev.5 — 2026-10-08

- Add bounded per-window history, literal search, twelve-message pages, native link preview and complete selected/page copying.
- Add optional cross-session history saving, retention settings and confirmed clearing, independent of appearance profiles.
- Preserve native message arguments, results, errors and later addon ownership during collection.
- Accept native geometry rounding when applying and restoring chat dimensions; report requested and read-back values on real refusals.

## 0.1.0-dev.4 — 2026-10-08

- Add message shadows, line spacing, fading controls, background margins and border opacity.
- Add independent tab fonts, shadows, active/inactive colors and borders, plus input appearance and layout controls.
- Save sparse individual window overrides with shared appearance profiles and preserve native input and chat behavior.
- Retry incomplete decorative setup and refused native artwork/button restoration.

## 0.1.0-dev.3 — 2026-10-08

- Preserve exact native API argument counts when installing or restoring chat scrolling.

## 0.1.0-dev.2 — 2026-10-08

- Keep chat appearance active when another addon takes over mouse-wheel scrolling.
- Preserve failure and settings rollback when an addon replaces the global error function.

## 0.1.0-dev.1 — 2026-10-08

- Add native chat appearance, per-window overrides, scrolling and input options.
- Add standalone and Booty Suite settings with reversible native customization.
- Preserve native tabs, channels, filters, docking, messages and item-link handling.
